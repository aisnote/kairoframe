HTML, web pages, footage
and sound, to video. Fast.

KairoFrame is a native video renderer. Write a film as HTML and CSS, record any web page, or join clips and pictures, and get MP4, MOV, WebM, GIF or HLS, about five times faster than Hyperframes on the same project.

Install on Windows 10/11 (64-bit): paste into cmd, PowerShell or Git Bash
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/aisnote/kairoframe/main/install.ps1 | iex"
Install on Linux (x86-64): paste into a terminal
curl -fsSL https://raw.githubusercontent.com/aisnote/kairoframe/main/install.sh | bash

What goes in, what comes out

One program for motion graphics, product promos, screen-recorded web apps and edited footage.

HTML projects

HTML and CSS timed by data- attributes, animated by a GSAP timeline. Hyperframes projects render as they are.

Any web page or built site

React, Vue or plain HTML, recorded frame by frame on a virtual clock: timers, requestAnimationFrame and CSS animations land exactly.

Footage and pictures

Video clips and images, cropped, masked, stacked in layers and joined segment after segment.

Sound

Music, voice-over and effects, with volume curves, speed changes and an effect chain: EQ, compressor, limiter, reverb, delay.

How it works

A film is an HTML page. Elements are shown by their data-start and data-duration; motion lives on one paused GSAP timeline.

<!-- index.html -->
<div data-composition-id="main" data-width="1920"
     data-height="1080" data-duration="6">
  <h1 id="title" data-start="0" data-duration="6">
    Launch day
  </h1>
  <video src="assets/hero.mp4" data-start="1" muted></video>
  <audio src="assets/music.mp3" data-start="0"
         data-volume="0.6" data-fade-out="1"></audio>
</div>
<script>
  const tl = gsap.timeline({ paused: true });
  tl.from("#title", { y: 60, opacity: 0, duration: 0.8 });
  window.__timelines = { main: tl };
</script>
1. Startkairoframe init my-film writes a starter page and notes for agents.
2. Checkkairoframe check finds text that is too small, cut off or overlapping, blank frames and missing files.
3. Lookkairoframe sheet draws the whole film as one picture of frames side by side.
4. Renderkairoframe render -o film.mp4; kairoframe compose for web pages and footage.

Made for coding agents

The one-line installer gives the KairoFrame skill to the agents on your machine. Then ask for a video in plain words.

Claude Code

Skill installed by the one-liner, or as a plugin:

/plugin marketplace add aisnote/kairoframe
/plugin install kairoframe@kairoframe
/kairoframe:install

Codex CLI

Skill in ~/.codex/skills and a section in ~/.codex/AGENTS.md, set up by the one-liner when Codex is installed.

"Make a 10 s 1080x1080 teaser
 for my app with three
 feature cards"

Gemini CLI & others

A section in ~/.gemini/GEMINI.md. Any other agent: point it at the skill file.

%LOCALAPPDATA%\KairoFrame\SKILL.md
~/.local/share/kairoframe/SKILL.md

Requirements

Windows 10/11 64-bit, or Linux x86-64Linux: glibc 2.38 or newer (Ubuntu 24.04, Debian 13, Fedora 39+) and an AVX2 CPU. About 250 MB on disk with ffmpeg and the headless browser the installer fetches.
Graphics card optionalNVIDIA, Intel or AMD H.264 encoders are used when present; otherwise x264 on the CPU.
Free to useThe binaries are free; the source code is not published. Third-party parts keep their licenses (LGPL libraries you can replace).
FontsFamilies named in CSS are fetched from Google Fonts on first use, so a project looks the same on every machine.
