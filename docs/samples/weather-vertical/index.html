The prompt

Given word for word to a fresh Claude Code session in an empty project made by kairoframe init. The session wrote index.html; nothing was edited by hand.

Make a 12-second vertical (1080x1920) social video: the weekly weather for a fictional city "Northport". Top: the city name, "This week" and a large animated icon of today's weather (a sun whose rays rotate and pulse). Middle: a temperature line chart for Monday to Sunday (invent plausible values in °C, highs and lows) that draws itself from left to right with dots popping at each day and the numbers counting up. Bottom: seven rows, one per day, sliding in one after another, each with a small animated icon drawn in SVG or CSS (sun, cloud drifting, rain with falling drops, thunder with a flash, snowflake turning), the high/low and a one-word summary. End with "Stay dry, Northport." Soft sky-blue to deep-blue gradient background with gently drifting clouds. Large readable type for phones (body text at least 40 px).

Work in this folder (a kairoframe project made by `kairoframe init`; read AGENTS.md). Check your work with `kairoframe check` and look at `kairoframe sheet`; fix what is wrong. Do not run `kairoframe render`: the film will be rendered separately.

Make it yourself

1. Install KairoFrame and Claude Code
curl -fsSL https://raw.githubusercontent.com/aisnote/kairoframe/main/install.sh | bash
2. Start an empty project and save the prompt above as prompt.txt in it
kairoframe init weather-vertical --size portrait --duration 12
cd weather-vertical
3. Let Claude write the film
claude -p "$(cat prompt.txt)" --model opus \
  --permission-mode acceptEdits \
  --allowedTools "Read,Write,Edit,Glob,Grep,Bash(kairoframe:*),Bash(ls:*)"
4. Render
kairoframe render -o weather-vertical.mp4 --crf 23

Or skip steps 2 and 3: download this sample's index.html into a folder and run step 4 there. A new session writes a different film each time; the cost of a run lands in the same range.
