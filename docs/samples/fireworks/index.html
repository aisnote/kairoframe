Canvas fireworks

A classic canvas fireworks demo from CodePen, with the clicks replaced by a scripted show.

Port of HTML5 canvas and javascript fireworks tutorial by Hansi on CodePen (MIT License). The session was given the original source as original.html and ported it to a film.

Music: “Rising Tide” Kevin MacLeod (incompetech.com), licensed under Creative Commons: By Attribution 4.0. Added in a second KairoFrame pass (with-music.html: the film plays as footage, the track as an <audio> clip with its volume and fades); the film itself is unchanged.

The prompt

Given word for word to a fresh Claude Code session in an empty project made by kairoframe init. The session wrote index.html; nothing was edited by hand.

original.html in this folder is the complete source of a public CodePen pen (MIT licensed): "HTML5 canvas and javascript fireworks tutorial" by Hansi (https://codepen.io/Hansi/pen/qZwMrB). Port it to this kairoframe project as a 12-second film at 1920x1080 that looks as much like the original as possible. The original runs on its own clock (requestAnimationFrame, timers, Math.random); in the film every frame must depend only on the film time: drive it from the GSAP timeline or the seek hook described in `kairoframe docs`, and replace Math.random with a seeded generator. The original launches fireworks on clicks and on its own; script a show instead: a few single launches, then a busier finale in the last 3 seconds. Keep the original's particles, trails and colours. Particle state must be computed from the time (for example by simulating from 0 up to the requested time with a fixed step), so that any frame can be drawn on its own. Keep the original's MIT license notice as a comment at the top of index.html ("Based on 'HTML5 canvas and javascript fireworks tutorial' by Hansi, https://codepen.io/Hansi/pen/qZwMrB, MIT License"), and put a small, unobtrusive credit in the bottom-right corner of the film: "HTML5 canvas and javascript fireworks tutorial — Hansi (CodePen, MIT)".

Work in this folder (a kairoframe project made by `kairoframe init`; read AGENTS.md). Check your work with `kairoframe check` and look at `kairoframe sheet`; fix what is wrong. Do not run `kairoframe render`: the film will be rendered separately.

Make it yourself

1. Install KairoFrame and Claude Code
curl -fsSL https://raw.githubusercontent.com/aisnote/kairoframe/main/install.sh | bash
2. Start an empty project and save the prompt above as prompt.txt in it
kairoframe init fireworks --duration 12
cd fireworks
2b. Put the original's source in the project
curl -L -o original.html https://aisnote.github.io/kairoframe/samples/fireworks/project/original.html
3. Let Claude write the film
claude -p "$(cat prompt.txt)" --model opus \
  --permission-mode acceptEdits \
  --allowedTools "Read,Write,Edit,Glob,Grep,Bash(kairoframe:*),Bash(ls:*)"
4. Render
kairoframe render -o fireworks.mp4 --crf 23

Or skip steps 2 and 3: download this sample's index.html into a folder and run step 4 there. A new session writes a different film each time; the cost of a run lands in the same range.
