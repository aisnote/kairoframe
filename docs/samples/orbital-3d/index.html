Orbital, in Three.js

A WebGL scene from Three.js, driven frame by frame by the film's clock.

Music: “Lightless Dawn” Kevin MacLeod (incompetech.com), licensed under Creative Commons: By Attribution 4.0. Added in a second KairoFrame pass (with-music.html: the film plays as footage, the track as an <audio> clip with its volume and fades); the film itself is unchanged.

The prompt

Given word for word to a fresh Claude Code session in an empty project made by kairoframe init. The session wrote index.html; nothing was edited by hand.

Make a 12-second cinematic 3D shot with Three.js (load it from a CDN, e.g. https://cdn.jsdelivr.net/npm/three@0.160.0/build/three.module.js). Scene: a stylised low-poly planet with flat-shaded oceans and continents slowly rotating, a thin glowing atmosphere rim, two small moons on tilted orbits, an orbital ring of tiny particles, and a deep starfield behind (stars placed with a seeded pseudo-random generator, never Math.random). The camera starts close on the planet's limb and pulls back and around in one smooth move to reveal the whole system. Title "ORBITAL" fades in with wide letter spacing at 3 s, subtitle "A WebGL scene rendered frame by frame" at 4 s, both fading out by 10 s. The 3D scene must be drawn from the film time only (seek-driven: render the scene for the current time on every seek, see `kairoframe docs`), with no requestAnimationFrame loop.

Work in this folder (a kairoframe project made by `kairoframe init`; read AGENTS.md). Check your work with `kairoframe check` and look at `kairoframe sheet`; fix what is wrong. Do not run `kairoframe render`: the film will be rendered separately.

Make it yourself

1. Install KairoFrame and Claude Code
curl -fsSL https://raw.githubusercontent.com/aisnote/kairoframe/main/install.sh | bash
2. Start an empty project and save the prompt above as prompt.txt in it
kairoframe init orbital-3d --duration 12
cd orbital-3d
3. Let Claude write the film
claude -p "$(cat prompt.txt)" --model opus \
  --permission-mode acceptEdits \
  --allowedTools "Read,Write,Edit,Glob,Grep,Bash(kairoframe:*),Bash(ls:*)"
4. Render
kairoframe render -o orbital-3d.mp4 --crf 23

Or skip steps 2 and 3: download this sample's index.html into a folder and run step 4 there. A new session writes a different film each time; the cost of a run lands in the same range.
