Marble flow shader

A WebGL fragment shader from CodePen, ported to a film: liquid marble in red and blue.

Port of Learning Shaders 003 by Sean Free on CodePen (MIT License). The session was given the original source as original.html and ported it to a film.

The prompt

Given word for word to a fresh Claude Code session in an empty project made by kairoframe init. The session wrote index.html; nothing was edited by hand.

original.html in this folder is the complete source of a public CodePen pen (MIT licensed): "Learning Shaders 003" by Sean Free (https://codepen.io/seanfree/pen/OOdQXZ). Port it to this kairoframe project as a 10-second film at 1920x1080 that looks as much like the original as possible. The original runs on its own clock (requestAnimationFrame, timers, Math.random); in the film every frame must depend only on the film time: drive it from the GSAP timeline or the seek hook described in `kairoframe docs`, and replace Math.random with a seeded generator. Keep the shader as it is; only its time uniform comes from the film time. Let the flow move clearly over the 10 seconds. Keep the original's MIT license notice as a comment at the top of index.html ("Based on 'Learning Shaders 003' by Sean Free, https://codepen.io/seanfree/pen/OOdQXZ, MIT License"), and put a small, unobtrusive credit in the bottom-right corner of the film: "Learning Shaders 003 — Sean Free (CodePen, MIT)".

Work in this folder (a kairoframe project made by `kairoframe init`; read AGENTS.md). Check your work with `kairoframe check` and look at `kairoframe sheet`; fix what is wrong. Do not run `kairoframe render`: the film will be rendered separately.

Make it yourself

1. Install KairoFrame and Claude Code
curl -fsSL https://raw.githubusercontent.com/aisnote/kairoframe/main/install.sh | bash
2. Start an empty project and save the prompt above as prompt.txt in it
kairoframe init shader-marble --duration 10
cd shader-marble
2b. Put the original's source in the project
curl -L -o original.html https://aisnote.github.io/kairoframe/samples/shader-marble/project/original.html
3. Let Claude write the film
claude -p "$(cat prompt.txt)" --model opus \
  --permission-mode acceptEdits \
  --allowedTools "Read,Write,Edit,Glob,Grep,Bash(kairoframe:*),Bash(ls:*)"
4. Render
kairoframe render -o shader-marble.mp4 --crf 23

Or skip steps 2 and 3: download this sample's index.html into a folder and run step 4 there. A new session writes a different film each time; the cost of a run lands in the same range.
