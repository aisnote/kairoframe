Make a 14-second film that shows how KairoFrame turns HTML into video. Left half: a dark code editor window (macOS-style traffic-light dots, file tab "index.html") in which HTML for a small title card types itself line by line with syntax highlighting (tags, attributes such as data-start and data-duration, strings, numbers) and a blinking caret driven by the timeline. Right half: a terminal window where, at 5 s, the command `kairoframe check` is typed and answers "0 errors, 0 warnings", then at 7 s `kairoframe render -o title.mp4` is typed, a progress bar fills with a frame counter going to 360 frames, and "done in 2.1 s" appears. At 10.5 s both windows scale down and slide apart and the finished title card from the code (big text "Hello, video." on a gradient) zooms forward in the middle as if it were playing. Use JetBrains Mono for code and a clean sans-serif for the card.

Work in this folder (a kairoframe project made by `kairoframe init`; read AGENTS.md). Check your work with `kairoframe check` and look at `kairoframe sheet`; fix what is wrong. Do not run `kairoframe render`: the film will be rendered separately.
