Aurora launch title

Kinetic typography and a living gradient for a product launch.

The prompt

Given word for word to a fresh Claude Code session in an empty project made by kairoframe init. The session wrote index.html; nothing was edited by hand.

Make a 12-second launch film for a fictional note-taking app called "Lumen". Open on a deep night-blue background where soft aurora ribbons (large blurred gradient shapes in teal, violet and pink) drift and breathe the whole time. At 0.5 s the words "Your ideas," and then "in full light." arrive word by word with a quick rise, slight overshoot and letter spacing that settles. At 4 s the headline clears upward and a logo mark assembles from six small rounded shapes that fly in from different directions and lock into a glowing ring, with the word "Lumen" fading up beside it. At 7.5 s three feature chips ("Instant search", "Offline first", "End-to-end encrypted") pop in one after another under the logo. From 10 s the end card reads "Available today" with a soft shine sweeping across it. Use a strong modern sans-serif from Google Fonts. Make it look like a polished Apple-style keynote moment.

Work in this folder (a kairoframe project made by `kairoframe init`; read AGENTS.md). Check your work with `kairoframe check` and look at `kairoframe sheet`; fix what is wrong. Do not run `kairoframe render`: the film will be rendered separately.

Make it yourself

1. Install KairoFrame and Claude Code
curl -fsSL https://raw.githubusercontent.com/aisnote/kairoframe/main/install.sh | bash
2. Start an empty project and save the prompt above as prompt.txt in it
kairoframe init aurora-launch --duration 12
cd aurora-launch
3. Let Claude write the film
claude -p "$(cat prompt.txt)" --model opus \
  --permission-mode acceptEdits \
  --allowedTools "Read,Write,Edit,Glob,Grep,Bash(kairoframe:*),Bash(ls:*)"
4. Render
kairoframe render -o aurora-launch.mp4 --crf 23

Or skip steps 2 and 3: download this sample's index.html into a folder and run step 4 there. A new session writes a different film each time; the cost of a run lands in the same range.
