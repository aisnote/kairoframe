The prompt

Given word for word to a fresh Claude Code session in an empty project made by kairoframe init. The session wrote index.html; nothing was edited by hand.

Make a 15-second bar chart race. Data (fictional, say so in a small note in a corner: "Fictional data"): monthly active users in millions of eight fictional apps (Nimbus, Paperkite, Orbitly, Fernway, Quillo, Tidepool, Brightloom, Cobalt) over 24 months from Jan 2025 to Dec 2026; invent smooth, believable curves where the leader changes at least three times. Show the top 8 as horizontal bars, each app with its own colour and a round initial badge, bars sliding smoothly to their new rank as values change, values counting up at the end of each bar, and a large month label ("Mar 2026") at the bottom right that changes with the data. Add a title "Who leads the month?" at the top. Clean dark dashboard look, generous spacing, tabular numbers. Generate the per-frame values in JavaScript from the monthly data with interpolation driven by the timeline, so every frame depends only on its time.

Work in this folder (a kairoframe project made by `kairoframe init`; read AGENTS.md). Check your work with `kairoframe check` and look at `kairoframe sheet`; fix what is wrong. Do not run `kairoframe render`: the film will be rendered separately.

Make it yourself

1. Install KairoFrame and Claude Code
curl -fsSL https://raw.githubusercontent.com/aisnote/kairoframe/main/install.sh | bash
2. Start an empty project and save the prompt above as prompt.txt in it
kairoframe init chart-race --duration 15
cd chart-race
3. Let Claude write the film
claude -p "$(cat prompt.txt)" --model opus \
  --permission-mode acceptEdits \
  --allowedTools "Read,Write,Edit,Glob,Grep,Bash(kairoframe:*),Bash(ls:*)"
4. Render
kairoframe render -o chart-race.mp4 --crf 23

Or skip steps 2 and 3: download this sample's index.html into a folder and run step 4 there. A new session writes a different film each time; the cost of a run lands in the same range.
